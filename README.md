# Simulacros Saber 11 en Antioquia

Datos de simulacros Saber 11 aplicados en Antioquia. Entrega 1, Unidad 2 de Matemática para
Ciencias de la Computación (Grupo 7, J02).

Variable de interés: Puntaje Global, escala 0 a 500. Áreas en escala 0 a 100.

Datos de menores de edad: solo entran archivos anonimizados, sin nombres, documentos ni
códigos de estudiante.

## Contenido

- `datos/consolidado_saber11.csv` — 1126 estudiantes en 16 instituciones.
- `datos/instituciones.csv` — municipio, sector, ubicación y promedio por institución.
- `referencia/` — ICFES oficial 2022-2, dataset `kgxf-xxbe` de datos.gov.co.
- `entrega/` — consolidado en Excel y cifras descriptivas.
